# Monolith Architecture

Architecture & interiors · Independent concept demo

A courtyard house that grows out of its dimensional drawing before a continuous interior walk.

**[Visit the live site ↗](https://northlight7.github.io/cinematic-monolith/)** · [Project notes & screenshots](https://github.com/northlight7/web-design-portfolio/tree/main/projects/monolith) · [Full portfolio](https://northlight7.github.io/web-design-portfolio/)

## What to try

Use the daylight study to move from morning to golden hour, then follow the camera into the courtyard.

## Design focus

The drawing and the building are the same object at different densities. A daylight control moves the shadows across the walls, louvers and water. Native pointers only: there is no custom cursor. Motion can be paused from the navigation, and the page keeps its content and controls when motion is off.

## Run locally

This is a buildless static site. Serve this repository with a static HTTP server, for example:

```sh
python3 -m http.server 8080
```

Then open http://localhost:8080 in your browser. Fonts, dependencies and all visual assets are hosted locally with the site. Nothing is fetched from a third-party runtime.
